Questions

How accurate is it?

On conventionally formatted resumes it reliably recovers contact details, employers, titles, dates, degrees and skills. It is a deterministic parser, not a language model: it does not hallucinate a job that is not on the page, and it will not rescue a resume laid out as a two-column graphic-design piece. Every field carries a confidence score so you can see which ones to check. Try the demo on your own hardest examples before subscribing.

What about scanned PDFs?

A scan is an image, so there is no text to extract. The API returns a warning telling you the document needs OCR first. Run it through an OCR tool and send the result as text.

Do you keep the resumes I send?

No. Documents are parsed in memory and the response is returned; nothing is written to storage or logs. The only things stored are your hashed API key and a monthly request count.

What happens if I exceed my quota?

The API returns 402 with a clear message and no charge. You can upgrade instantly from the billing portal, or wait for the next monthly period. There is no surprise overage billing.

If the core is MIT, why pay?

You are paying for the hosting, not the algorithm — a maintained endpoint, PDF and DOCX extraction that works in any runtime, and updates as resume formats drift. If you would rather run it yourself, that is a supported and encouraged path.
